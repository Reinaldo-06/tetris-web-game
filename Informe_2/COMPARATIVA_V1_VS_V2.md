## 🔄 FLUJO DE USUARIO: ANTES vs AHORA

### ANTES (v1.0)
```
Menú
  ├─ Selecciona tamaño
  ├─ Selecciona nivel
  └─ INICIAR JUEGO
        │
        └─ Juega normalmente
             └─ Game Over
                  └─ Puntuación perdida
                       └─ Reiniciar o Menú
```

### AHORA (v2.0)
```
Menú
  ├─ Selecciona tamaño
  ├─ Selecciona MODO (nuevo: 3 opciones)
  ├─ Selecciona nivel
  ├─ Ve descripción del modo (nuevo)
  └─ INICIAR JUEGO
        │
        ├─ Ver Récords (nuevo)
        └─ Juega con más opciones:
             ├─ P: Pausa (nuevo)
             ├─ R: Reinicia (nuevo)
             ├─ M: Mute (nuevo)
             ├─ ESC: Menú (nuevo)
             └─ Efectos: Partículas (nuevo), Música (mejorado)
                  │
                  ├─ Si Game Over:
                  │    ├─ Muestra puntuación
                  │    ├─ Muestra récords (nuevo)
                  │    └─ Puntuación se guarda (nuevo)
                  │
                  └─ Si Sandbox: Nunca Game Over (nuevo)
                       └─ Práctica infinita
```
