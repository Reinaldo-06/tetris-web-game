┌─ SOLUCIÓN 4: Nueva Fórmula de Progresión (tetris.js) ───────────────────────┐
│                                                                              │
│  ✓ Fórmula que respeta minLevel                                            │
│  ✓ El nivel nunca desciende                                               │
│  ✓ Matemáticamente clara y documentada                                     │
│                                                                              │
│  FÓRMULA ANTERIOR (INCORRECTA):                                             │
│  const newLevel = Math.floor(lines / 5) + 1;                               │
│                                                                              │
│  FÓRMULA NUEVA (CORRECTA):                                                 │
│  const linesAboveInitial = Math.max(0, lines - (minLevel - 1) * 5);        │
│  const newLevel = minLevel + Math.floor(linesAboveInitial / 5);            │
│                                                                              │
│  EXPLICACIÓN PASO A PASO:                                                   │
│                                                                              │
│  Parámetro: minLevel = 4, lines = 25                                       │
│                                                                              │
│  Paso 1: Calcular "líneas virtuales" del nivel anterior                    │
│          linesNeeded = (minLevel - 1) * 5 = (4 - 1) * 5 = 15               │
│                                                                              │
│  Paso 2: Restar líneas virtuales de líneas reales                          │
│          linesAboveInitial = 25 - 15 = 10                                  │
│          (Significa: 10 líneas POR ENCIMA del nivel inicial)               │
│                                                                              │
│  Paso 3: Calcular niveles adicionales (cada 5 líneas = 1 nivel)            │
│          additionalLevels = 10 / 5 = 2                                     │
│                                                                              │
│  Paso 4: Nuevo nivel = minLevel + niveles adicionales                      │
│          newLevel = 4 + 2 = 6                                              │
│                                                                              │
│  GARANTÍA: newLevel nunca < minLevel porque:                               │
│          newLevel = minLevel + Math.max(0, Math.floor(...))                │
│          El Math.max(0, ...) asegura que el segundo término sea ≥ 0        │
│          Por lo tanto: newLevel ≥ minLevel + 0 = minLevel                  │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
